# Локальный резервный сервер — эксперимент

Этот прототип проверяет, что «Диктор конспектов» сможет общаться со **вторым сервером** в том же формате, что и с Cloudflare Workers. Он **не опубликован**, не меняет рабочее приложение, не создаёт Google Cloud-ресурсы и **не использует OpenRouter**.

Сервер запускается **только на 127.0.0.1**, а браузерные запросы разрешены только с localhost. Его нельзя использовать как публичный сервер для пользователей. Внутренние счётчики — тестовые и сбрасываются при перезапуске; это не настоящая защита от злоупотреблений.

## Самая простая проверка без нейросети

Открой Git Bash в папке `helper-with-conspects` на тестовой ветке:

```bash
npm run test:backup
```

Тест сам поднимет сервер на случайном локальном порту, проверит его ответы, потоковый формат SSE, CORS, ошибки и ограничения запросов, затем выключит. **Никакие ключи или аккаунты не нужны.**

## Запуск тестового сервера

В первом окне Git Bash:

```bash
npm run backup:lab
```

Открой в браузере `http://127.0.0.1:4174/health`. Ожидаем `"mode":"mock"`, `"localOnly":true`, `"cloudCostUsd":0`. Нажми **Ctrl+C**, чтобы остановить сервер.

Для проверки API можно открыть **второе окно Git Bash** и запустить `npm run test:backup`. Этот тест использует свой экземпляр сервера, а не уже запущенный процесс.

## Настоящая локальная Qwen через Ollama — по желанию

Если Ollama уже работает и `ollama list` показывает `qwen2.5:0.5b`, можно проверить настоящий ответ **без Google Cloud**. В Git Bash:

```bash
BACKUP_LAB_MODE=ollama MODEL_NAME=qwen2.5:0.5b npm run backup:lab
```

Второе окно: 

```bash
node server/backup-lab-check.mjs
```

Скрипт обращается к `http://127.0.0.1:4174` и проверяет формат OpenAI-совместимых ответов. Нейросеть используется только на твоём компьютере. Запросы могут нагружать процессор, но **облачных расходов нет**.

## Полная локальная проверка: приложение → резервный сервер → Ollama

Мы также можем проверить **существующий браузерный клиент приложения с настоящей Qwen** без ручного изменения настроек. Нужны установленная и запущенная Ollama, модель `qwen2.5:0.5b`, Node.js и Playwright Chromium:

```bash
npm ci
npx playwright install chromium
MODEL_NAME=qwen2.5:0.5b npm run test:backup:ollama
```

Команда сама откроет Chromium без интерфейса, временно запустит оба локальных HTTP-сервера, настроит только тестовый браузер на резервный адрес и выполнит два коротких текстовых запроса — обычный JSON и потоковый SSE. Она проверит, что ответы действительно пришли из Ollama (а не из имитации), и выключит временные серверы.

**Если `backup:lab` уже запущен в другом терминале, его можно предварительно остановить (Ctrl+C), но это не обязательно:** автоматическая проверка использует случайный свободный локальный порт.

Ожидается `PASS: PWA -> local backup -> Ollama; JSON and SSE worked in Chromium.`

Модель 0.5B не обязана хорошо понимать сложные конспекты. Здесь проверяется только успешная передача настоящих текстовых ответов, не качество анализа документов. Никаких облачных сервисов или платёжных данных тест не использует.

## Как это соотносится с существующим приложением

- Основная версия по-прежнему работает на GitHub Pages и Cloudflare Workers. Мы **не меняем** `server/worker.js`, `server/wrangler.toml` или `js/config.js` в этом эксперименте.
- Уже реализованный клиент поддерживает резервные адреса `FREE_PROXY_LIST`; новый сервер повторяет необходимые маршруты `/v1/models` и `/v1/chat/completions` (и без `/v1`).
- Режим `mock` **не умеет создавать настоящие конспекты**, а Ollama-модель 0.5B может ошибаться в сложном JSON, фото и учебном анализе. Прототип пока принимает только текст.
- Проверять сервер с рабочей версии сайта на GitHub Pages **не надо**: специально запрещены запросы из внешних сайтов к локальному серверу.
- Прежде чем делать публичный резервный сервер, понадобятся реальная авторизация и централизованные лимиты расходов, секреты, аудит безопасности, HTTPS и подходящий AI-провайдер. Перенос тестового файла «как есть» в облако запрещён.

## Какой результат считать успешным

```text
PASS: local backup mock API contract
```

А для режима Ollama — `PASS: local Ollama backup API`.

**Никаких банковских карт, платных ключей, Cloudflare-выкладки или Google Cloud Console для этих проверок не требуется.**
