# Сервер бесплатного режима

С этим сервером приложению не нужен ключ от пользователя: запросы к нейросети идут через сервер, а он ходит в OpenRouter (или другой сервис) с вашим ключом. Ключ хранится в настройках сервера и в браузер не попадает.

Сервер — один файл, [`worker.js`](worker.js), он работает на Cloudflare Workers и выкладывается туда автоматически из GitHub. Бесплатный тариф Cloudflare даёт 100 000 запросов в день, карта для него не нужна.

## 1. Ключ OpenRouter для сервера

Зайдите на [openrouter.ai/keys](https://openrouter.ai/keys) (можно войти через Google) и создайте **отдельный** ключ, например «Учёба — сервер». Скопируйте его, он показывается один раз.

Пополнять баланс не нужно. Сервер сам выбирает бесплатные модели OpenRouter (у них в названии `:free`) и при каждом запросе пробует до трёх таких моделей, лучшие первыми.

Квота провайдера общая для всех пользователей приложения. Лимиты сервера ограничивают расход, но не увеличивают квоту OpenRouter. Резервный адрес с тем же ключом также не добавляет запросов.

Число запросов на конспект зависит от фотографий, объёма текста, числа тем, проверки полноты и повторов. Приложение показывает приблизительную оценку; фактический расход может быть выше. После исчерпания квоты сохранённые результаты можно использовать при следующей попытке.

Для платной подготовки нужны отдельный ключ с месячным ограничением расходов и явное включение PAID_NOTES_ENABLED. Простая замена MODELS на платную модель не включает платный режим OpenRouter. Текущие квоты и цены проверяйте в кабинете провайдера; обещать фиксированную стоимость конспекта без замеров нельзя.

## 2. Cloudflare и GitHub

Сервер выкладывается автоматически из GitHub (проверка «Сервер» во вкладке Actions). От вас нужно один раз завести аккаунт и положить в GitHub три значения.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up), хватит почты. Подтвердите почту по письму.
2. Слева откройте **Workers & Pages**. Если Cloudflare попросит выбрать имя поддомена (`что-то.workers.dev`), введите любое, например свой ник. Из него получится адрес сервера.
3. **Номер аккаунта.** На той же странице справа есть **Account ID**. Скопируйте его.
4. **Токен.** Справа вверху значок профиля → **Profile** → **API Tokens** → **Create Token**. Напротив шаблона **Edit Cloudflare Workers** нажмите **Use template**. В **Account Resources** выберите свой аккаунт, остальное не трогайте. **Continue to summary** → **Create Token**, скопируйте токен (он показывается один раз). Этот токен умеет только выкладывать серверы-воркеры, к оплате и остальным настройкам доступа у него нет.
5. **Секреты в GitHub.** В репозитории: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**. Добавьте три секрета:

   | Name | Secret |
   |---|---|
   | `CLOUDFLARE_API_TOKEN` | токен из пункта 4 |
   | `CLOUDFLARE_ACCOUNT_ID` | номер аккаунта из пункта 3 |
   | `OPENROUTER_KEY` | ключ OpenRouter из первой части |

   Значения секретов потом не видно никому, даже вам. Ими пользуется только автоматическая выкладка.
6. Запустите выкладку: **Actions** → **Сервер** → **Run workflow**. Через минуту в итогах запуска появится адрес сервера, вида `https://konspekt-free.ваше-имя.workers.dev`.

Откройте этот адрес с телефона без VPN. Если на странице `ok`, сервер работает. Если адрес не открывается, Cloudflare можно подключить к своему домену (**Settings** → **Domains & Routes** у воркера).

Если что-то пошло не так, токен удаляется в Cloudflare одной кнопкой (**API Tokens** → **Delete**), и доступ сразу пропадает.

**Вручную, без GitHub.** **Workers & Pages** → **Create** → **Create Worker**, имя `konspekt-free`, **Deploy** → **Edit code**, вставьте содержимое [`worker.js`](worker.js), снова **Deploy**. Потом **Settings** → **Variables and Secrets** → **Add**: тип **Secret**, имя `OPENROUTER_KEY`, значение — ключ OpenRouter.

## 3. Включить в приложении

Впишите адрес сервера в [`js/config.js`](../js/config.js), в строку `FREE_PROXY_URL`, и выпустите новую версию приложения (поднимите версию в `sw.js` и `index.html`, см. [docs/development.md](../docs/development.md)).

После этого новые пользователи начинают без ключа. Если ключ уже указан, приложение продолжает работать с ним. Свой ключ всегда можно поставить в мастере: «У меня свой ключ OpenRouter».

## Настройки

Их можно поменять в **Settings** → **Variables and Secrets** (тип **Text**), без правки кода:

| Имя | По умолчанию | Что это |
|---|---|---|
| `ALLOWED_ORIGINS` | `https://stairrax.github.io` | с каких сайтов принимать запросы, через запятую |
| `MODELS` | `free` | `free` — бесплатные модели OpenRouter, сервер подбирает их сам; либо список моделей через запятую. Для OpenRouter допускаются только варианты `:free` |
| `UPSTREAM` | `https://openrouter.ai/api/v1` | куда ходит сервер: OpenRouter или другой сервис с OpenAI-совместимым API |
| `DAILY_PER_DEVICE` | `170` | общий предел запросов в сутки на одно устройство |
| `DAILY_NOTES` | `100` | запросов на создание и подготовку конспектов в сутки на устройство |
| `DAILY_QUESTIONS` | `70` | запросов на вопросы, тесты и другие действия в сутки на устройство |
| `DAILY_PER_IP` | `500` | запросов в сутки на один IP-адрес (общежитие или университетский Wi-Fi — это один адрес) |
| `DAILY_TOTAL` | `900` | общий дневной предел запросов к серверу; фактический лимит OpenRouter может быть меньше |
| `MAX_TOKENS` | `16000` | наибольшая длина одного ответа |
| `FALLBACK_AI_MODELS` | см. выше | модели запасного ИИ Workers AI, через запятую; `off` — выключить |
| `PAID_NOTES_ENABLED` | `false` | разрешить платную модель для подготовки конспектов после настройки отдельного ключа |

Для платной подготовки нужен **отдельный** секрет `OPENROUTER_PAID_KEY` с месячным лимитом не более $20, настроенным в OpenRouter. Сервер проверяет лимит и остаток через OpenRouter перед запросом; без подходящего лимита, ключа или при ошибке проверки он использует бесплатный маршрут. Прежде чем включать `PAID_NOTES_ENABLED`, пополните счёт и настройте ограничение ключа в OpenRouter. Модель `google/gemini-2.5-flash-lite` и максимальная цена за миллион токенов ($0.15 вход, $0.60 выход) заданы сервером; цена может измениться, её нужно проверять перед включением. Предел ключа касается только запросов через этот ключ, а не других ключей аккаунта.

Устройство определяется локальным идентификатором, а IP может быть общим для вуза. Эти лимиты распределяют нагрузку, но не заменяют авторизацию: идентификатор и тип запроса можно подменить. Не используйте их вместо ограничения расходов на ключе.

## Запасной ИИ (Cloudflare Workers AI)

Вопросы сначала направляются в Workers AI, а если он недоступен — к бесплатной модели OpenRouter. Для конспектов Workers AI остаётся запасным вариантом. У Cloudflare свой дневной запас; его расход зависит от модели и размера запросов и виден в панели Cloudflare → **AI** → **Workers AI**. Включён привязкой `[ai]` в [`wrangler.toml`](wrangler.toml).

- Модели проще, чем у OpenRouter, и по-русски пишут хуже; фото страниц они не читают (такие запросы запасному не передаются).
- Тексты конспекта в этом случае обрабатывает Cloudflare — тот же сервис, через который и так идёт запрос.
- Список моделей: переменная `FALLBACK_AI_MODELS` (через запятую; первая, что ответит, и берётся; значение `off` выключает запасной). По умолчанию: `@cf/mistralai/mistral-small-3.1-24b-instruct`, `@cf/meta/llama-3.3-70b-instruct-fp8-fast`, `@cf/google/gemma-3-12b-it`, `@cf/meta/llama-3.1-8b-instruct`. Каталог Cloudflare меняется: если к модели нет доступа или её сняли с обслуживания, сервер берёт следующую и час к ней не возвращается (диагностика показывает временно исключённые модели). Тяжёлая 70B тратит бесплатный дневной запас в несколько раз быстрее лёгких, поэтому она не первая.
- /health сообщает конфигурацию и доступность метаданных без вызова нейросети. Параметр test=1 не запускает модель. Активная проверка при публикации использует обычный /chat/completions и общие квоты.

## Из России без VPN

Проверка из России без VPN (ноябрь 2026, мобильный интернет) показала:

| Адрес | Что происходит |
|---|---|
| Сайт приложения на GitHub Pages | открывается |
| `*.workers.dev` | не открывается вообще — домен закрыт |
| `openrouter.ai` | открывается страница Cloudflare «Sorry, you have been blocked» |

Из этого следует: сеть Cloudflare доступна (её страница дошла), закрыт именно домен `workers.dev`. А **свой ключ OpenRouter без VPN не спасает**: OpenRouter сам не пускает запросы с российских адресов. Значит, работать может только сервер-посредник на адресе, который открывается.

**Как починить: свой домен.** Подойдёт любой домен (дешевле всего `.ru`, `.top`, `.xyz`).

1. Добавьте домен в Cloudflare (бесплатный тариф) и пропишите у регистратора серверы имён, которые Cloudflare выдаст.
2. В [`wrangler.toml`](wrangler.toml) раскомментируйте блок `[[routes]]` и впишите поддомен, например `ai.ваш-домен.ru`.
3. Запустите в Actions «Сервер» — Cloudflare сам создаст запись DNS и выпустит сертификат.
4. Добавьте новый адрес **первой строкой** в `FREE_PROXY_URLS` в [`js/config.js`](../js/config.js), оставив старый запасным, и поднимите версию приложения.

Приложение само берёт первый адрес, который отвечает, запоминает его и переключается на запасной, если связи нет. Так переход ничего не ломает: у кого открывается `workers.dev`, продолжат ходить через него.

**Пока домена нет**, в приложении есть **Настройки → Проверить связь**: она показывает, что открывается из этой сети (каждый адрес сервера отдельно) и что делать — свой ключ OpenRouter, VPN или другая сеть. Сообщение об ошибке при обрыве связи тоже говорит про VPN. Готовые конспекты диктуются и без интернета.

## Если у кого-то «Бесплатный режим недоступен»

Откройте в браузере `адрес-сервера/health` (например, `https://konspekt-free.имя.workers.dev/health`) — лучше с того телефона и из той сети, где ошибка. Сервер покажет, что он видит оттуда:

| Поле | Что значит |
|---|---|
| `keyOnServer` | `false` — секрет `OPENROUTER_KEY` на сервере не задан: запустите «Сервер» в Actions |
| `keyCheck.status` | `200` — OpenRouter принял ключ; `401` — ключ отозван или неверный (создайте новый и обновите секрет `OPENROUTER_KEY` в GitHub); `402` — на счёте минус; `403` — отказ (регион, проверка на ботов) |
| `keyCheck.freeTier` | `true` — ключ без пополнения: у всех бесплатных моделей общий лимит на день (около 50 запросов на всё приложение) |
| `models` | какие бесплатные модели видит сервер; пусто — смотрите `modelsProblem` |
| `where` | через какой город и страну пришёл запрос — если у друга не работает, а у вас да, сравните |

Пользователю сообщение об ошибке теперь заканчивается кодом, например `(код: upstream-403)`: `upstream-401/402/403` — ответ OpenRouter на ключ, `models-http-403`, `models-empty`, `models-unreachable` — не удалось получить список бесплатных моделей, `upstream-unreachable` — OpenRouter не ответил. Попросите прислать скриншот с кодом.

## От чего это защищает и от чего нет

Сервер проверяет Origin, выбирает модель и ограничивает длину ответа. Счётчики хранятся в Cloudflare Durable Object и обновляются совместно для всех экземпляров сервера; сутки считаются по UTC. Origin и идентификатор устройства можно подделать, а общий IP может объединять пользователей одной сети. При использовании платной модели обязательно задайте ключу лимит расходов в OpenRouter.

Фото страниц — самые тяжёлые запросы. На бесплатном тарифе Cloudflare время работы на один запрос ограничено, так что если распознавание фото через сервер будет сбоить, напишите в [Issues](https://github.com/Stairrax/helper-with-conspects/issues).

Настройки выкладки — в [`wrangler.toml`](wrangler.toml) и [`.github/workflows/server.yml`](../.github/workflows/server.yml).


## Планирование нагрузки

Измерьте число запросов, входных и выходных токенов, время и число повторов для типичных материалов. Суточная вместимость — меньшая из квоты провайдера и серверного лимита, делённая на измеренный расход сценария; вопросы и OCR учитываются отдельно. Это оценка, а не гарантия доступности.

Origin — защита браузерного доступа, не удостоверение личности. Номер устройства можно сменить; общие и IP-лимиты сдерживают расход, но для публичного масштабирования нужны отдельная аутентификация и защита от автоматизации. Платный маршрут по умолчанию выключен.
