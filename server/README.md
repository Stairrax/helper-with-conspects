# Сервер бесплатного режима

С этим сервером приложению не нужен ключ от пользователя: запросы к нейросети идут через сервер, а он ходит в OpenRouter с вашим ключом. Ключ хранится в настройках сервера и в браузер не попадает.

Сервер — один файл, [`worker.js`](worker.js), он работает на Cloudflare Workers. Бесплатный тариф Cloudflare даёт 100 000 запросов в день, карта для него не нужна.

## 1. Ключ OpenRouter для сервера

1. Зайдите на [openrouter.ai/keys](https://openrouter.ai/keys) и создайте **отдельный** ключ, например «Диктор — сервер».
2. В поле **Credit limit** поставьте предел расходов, например 5 $. Если на сервер придёт слишком много запросов, он просто перестанет отвечать, и больше этой суммы не спишется. Если есть выбор, как часто обнулять лимит, выберите раз в месяц.
3. Пополните баланс в разделе **Credits**. Российские карты OpenRouter не принимает, но там же можно заплатить криптовалютой.

По умолчанию сервер работает на `google/gemini-2.5-flash`: модель недорогая, понимает фото страниц и хорошо пишет по-русски. Подготовка одного конспекта обходится примерно в 2–5 центов, ответ на вопрос — в доли цента.

## 2. Сервер на Cloudflare

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up), хватит почты.
2. Слева **Workers & Pages** → **Create** → **Create Worker**. Назовите его, например, `konspekt-free` и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё, что там есть, вставьте содержимое [`worker.js`](worker.js) и снова нажмите **Deploy**.
4. Вернитесь к воркеру: **Settings** → **Variables and Secrets** → **Add**. Тип **Secret**, имя `OPENROUTER_KEY`, значение — ключ из первого шага. Сохраните.
5. Откройте адрес воркера, он вида `https://konspekt-free.ваше-имя.workers.dev`. Если на странице написано `ok`, сервер работает.

Проверьте этот адрес и с телефона, без VPN. Если он не открывается, Cloudflare можно подключить к своему домену (**Settings** → **Domains & Routes**).

## 3. Включить в приложении

Впишите адрес сервера в [`js/config.js`](../js/config.js), в строку `FREE_PROXY_URL`, и выпустите новую версию приложения (поднимите версию в `sw.js` и `index.html`, см. [docs/development.md](../docs/development.md)).

После этого новые пользователи начинают без ключа. Если ключ уже указан, приложение продолжает работать с ним. Свой ключ всегда можно поставить в мастере: «У меня свой ключ OpenRouter».

## Настройки

Их можно поменять в **Settings** → **Variables and Secrets** (тип **Text**), без правки кода:

| Имя | По умолчанию | Что это |
|---|---|---|
| `ALLOWED_ORIGINS` | `https://stairrax.github.io` | с каких сайтов принимать запросы, через запятую |
| `MODELS` | `google/gemini-2.5-flash` | модель; можно несколько через запятую — остальные станут запасными |
| `DAILY_PER_DEVICE` | `300` | запросов в сутки на одно устройство (конспект — примерно 10–30 запросов) |
| `DAILY_PER_IP` | `1500` | запросов в сутки на один IP-адрес (общежитие или университетский Wi-Fi — это один адрес) |
| `MAX_TOKENS` | `16000` | наибольшая длина одного ответа |

## От чего это защищает и от чего нет

Сервер принимает запросы только со страниц приложения, сам выбирает модель и ограничивает длину ответа, поэтому дорогую модель через него не вызвать. Дневные лимиты считаются в памяти сервера, то есть приблизительно. Если кто-то специально захочет потратить ваши деньги, его остановит лимит на ключе из первого шага. Поэтому лимит обязателен.

Фото страниц — самые тяжёлые запросы. На бесплатном тарифе Cloudflare время работы на один запрос ограничено, так что если распознавание фото через сервер будет сбоить, напишите в [Issues](https://github.com/Stairrax/helper-with-conspects/issues).

Если хочется ставить через командную строку, рядом лежит [`wrangler.toml`](wrangler.toml): `npx wrangler deploy`, потом `npx wrangler secret put OPENROUTER_KEY`.
