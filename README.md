# Диктор конспектов

Мобильное PWA: диктует конспекты голосом короткими кусками, останавливается по слову «стоп», отвечает на вопросы через нейросеть и продолжает с того же места.

**[▶ Попробовать](https://stairrax.github.io/helper-with-conspects/)**: откройте в Chrome на Android, ничего устанавливать не нужно.
Понадобится бесплатный ключ [OpenRouter](https://openrouter.ai/keys): мастер при первом запуске проведёт по шагам, это пара минут.

- **Диктует кусками по 1–3 предложения** с паузой на запись; темы, план и оценка времени — по вашему конспекту (текст, PDF, DOCX, фото страниц).
- **«Стоп» голосом или кнопкой** обрывает речь сразу; можно спросить «почему…», нейросеть ответит с учётом конспекта, и диктовка вернётся к прерванному куску.
- **Живой голос прямо на телефоне** (Silero «Бая» и другие): без интернета и лимитов, с ударениями по смыслу и интонацией лектора; формулы — словами и чуть медленнее.
- **Учиться, а не только записывать**: самопроверка после темы, повторение слабых мест, формулы — отдельным блоком для самостоятельного разбора, режим «Только слушаю» для транспорта.
- **Данные — только на вашем телефоне**: конспекты и ключ никуда не отправляются, кроме выбранной вами нейросети.

## Лицензии

У кода и у моделей разные лицензии:

- **Код приложения** (`index.html`, `css/`, `js/`, `sw.js`, `icons/` и остальное, кроме перечисленного ниже) — [MIT](LICENSE) ([перевод на русский](LICENSE.ru.md)): можно использовать, менять и распространять, в том числе в коммерческих проектах, сохранив уведомление об авторстве.
- **Модель Silero** в [`voices/silero-ru/`](voices/silero-ru/) — © [Silero Team](https://github.com/snakers4/silero-models), [CC BY-NC-SA 4.0](voices/silero-ru/LICENSE): **только некоммерческое использование**, с указанием авторов, производные — на тех же условиях. Коммерческому проекту нужно убрать эту папку или договориться с авторами.
- **Шрифты** Onest и Unbounded в [`fonts/`](fonts/) — [SIL Open Font License 1.1](fonts/OFL.txt).
- **Голоса Piper** скачиваются по ссылке с Hugging Face (`rhasspy/piper-voices`) и в репозиторий не входят; у каждого голоса своя лицензия — в его карточке модели.
- Библиотеки, которые загружаются с CDN (onnxruntime-web, piper-wasm, pdf.js, mammoth.js), — по их собственным лицензиям.

Это не юридическая консультация, а описание того, что откуда взято.
