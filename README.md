# Диктор конспектов

Мобильное веб-приложение (PWA), которое диктует конспекты голосом короткими кусками, мгновенно останавливается по команде «стоп» или по вопросу, отвечает на вопрос через нейросеть и продолжает с того же места.

Без сборки и без бэкенда: обычные статические файлы. Целевая платформа — Chrome на Android.

## Возможности

- **Материал**: несколько конспектов; вставка текста, файлы `.txt`, `.md`, `.pdf` (pdf.js), `.docx` (mammoth.js), фото страниц (распознаёт Gemini). PDF-сканы без текстового слоя автоматически отправляются в Gemini как изображения.
- **Время и приоритет**: «сколько у меня времени» и порядок: «сначала сложное», «сначала простое», «как в конспектах».
- **Нейросеть на выбор**: OpenRouter (по умолчанию, работает из России, есть бесплатные модели), Claude (Anthropic API), Google Gemini, DeepSeek, Mistral или любой OpenAI-совместимый адрес. Для каждого провайдера можно указать свой адрес API (например, прокси).
- **Анализ** (один раз): разбиение на темы без потери текста (модель только расставляет границы между блоками исходника, сам текст не переписывается), сложность 1–5, зависимости, план с учётом зависимостей, оценка времени по объёму и сложности. План можно править: переставлять, пропускать темы, начинать с любой темы, подогнать паузу под бюджет времени.
- **Куски для диктовки**: 1–3 предложения, весь исходный материал, переформулированный для устной речи, формулы словами, пояснения и примеры в сложных местах. **Проверка полноты**: список всех пунктов исходника с номерами кусков, где они покрыты; непокрытые пункты догенерируются. Куски готовятся в фоне с опережением — диктовку можно начинать сразу после анализа.
- **Диктовка**: SpeechSynthesis `ru-RU`, пауза между кусками (по умолчанию 3 с, дольше для сложных тем и длинных кусков), прогресс по темам и времени, текст куска можно скрыть. Позиция сохраняется — можно закрыть и продолжить.
- **Прерывание**: большая кнопка «СТОП / ВОПРОС» срабатывает на касание (`pointerdown`) и сразу обрывает речь. Голосовые команды: «стоп», «пауза», «дальше», «записал» / «готово», «повтори», «повтори тему», «медленнее», «быстрее», «пропусти тему», «продолжай». Вопрос можно начать сразу словами «почему…», «что такое…», «вопрос…». Если диктовка остановилась, приняв речь за вопрос, а вопроса так и не прозвучало, через 6 секунд она продолжится сама.
- **Микрофон и «режим звонка» (Android)**: включённый микрофон переводит звук телефона в «режим звонка» — голос обрывается, глохнет и звучит «как по телефону» (с Bluetooth-наушниками особенно: они не умеют одновременно хороший звук и микрофон). Настройки → Диктовка → **Микрофон**:
  - **После «СТОП»** — микрофон включается только после кнопки «СТОП» или кнопки на наушниках; звук всегда обычный;
  - **В паузах** (по умолчанию на Android) — микрофон слушает в паузах между кусками («записал», «повтори», вопросы) и выключается за 1,5 с до следующего куска, чтобы звук успел вернуться в обычный режим;
  - **Всегда** — можно перебить голосом посреди фразы, но на Android звук будет «как по телефону» (по умолчанию на компьютере).
  Голос начинает говорить не раньше чем через 1,5 с после выключения микрофона (с Bluetooth-наушниками — через 3 с).
  - **Bluetooth-наушники: микрофон только после «СТОП»** (включено по умолчанию): приложение само замечает подключённые Bluetooth-наушники по списку аудиоустройств и, пока они подключены, не включает микрофон без «СТОП» — голос звучит чисто. Отключили наушники — команды в паузах снова работают.
- **«Записал»**: в паузе — сразу следующий кусок; пока читается новый кусок — ничего не пропускается. Одна и та же команда, которую распознавание прислало дважды, выполняется один раз. «Повтори» после остановки посреди куска повторяет именно его.
- **Распознанная речь без повторов**: Chrome на Android присылает текст с наложением — каждый следующий кусок повторяет всё сказанное раньше. Приложение оставляет только новое, поэтому длинный вопрос показывается и уходит нейросети один раз, а команда в конце длинной фразы («…записал») срабатывает.
- **Защита от эха**: фразы, совпадающие по словам и порядку с только что произнесённым, игнорируются; во время диктовки — и запоздавшее распознавание, и то, как студент вполголоса повторяет продиктованное, пока пишет.
- **Вопросы**: голосом или текстом; нейросеть отвечает с учётом всего конспекта и уже продиктованного, ответ озвучивается по мере генерации (потоково). Затем «Продолжаем?» — по «да» / «дальше» диктовка возвращается к началу прерванного куска. После каждой темы — «Есть вопросы?».
- **Режимы**: «всё подряд» (после темы короткая пауза на вопросы) или «по теме с вопросами после каждой» (ждёт ответа).
- **Резервная копия**: Настройки → Данные → «Сохранить копию» — один файл со всеми настройками, ключами, конспектами и прогрессом (через «Поделиться» его удобно положить в Google Диск или Telegram). «Восстановить из копии» есть там же и на первом экране мастера настройки. В файле ключи API — не пересылайте его.
- Wake Lock во время диктовки, офлайн-оболочка (service worker), повтор запросов при ошибках сети и лимитах API, большие конспекты обрабатываются по частям.

## Учебные функции

- **Самопроверка после темы** — 2–3 вопроса по теме; отвечаете голосом или текстом, нейросеть говорит, что верно, а что упущено. «Не знаю» — назовёт правильный ответ, «пропусти» — следующий вопрос.
- **Слабые места и повторение** — приложение запоминает темы, где были ошибки в самопроверке или много вопросов, и назначает повторение: слабые — на завтра, остальные — через 3 дня, дальше реже. В плане у таких тем отметки «слабая» / «повторить».
- **Быстрое повторение** — на вкладке «План»: читает главное по темам без пауз (все пройденные или только те, что пора повторить).
- **Пауза «пока не скажу»** — вместо паузы по времени ждёт «дальше», «готово» или «записал». Пауза по времени сама удлиняется, если часто просите повторить.
- **По буквам** — «как пишется фотосинтез» или просто «по буквам» (продиктует сложные слова из последнего куска).
- **Перерывы** — каждые 40 минут (настраивается) предлагает 5 минут отдыха и потом возвращает к тому же месту.
- **Кнопки наушников** (экспериментально) — пуск/пауза останавливает и продолжает, вперёд/назад — следующий кусок и повтор.
- **Несколько предметов** — переключение по названию предмета под заголовком экрана; у каждого свой план и прогресс.
- **Экспорт** — «Сохранить конспект и вопросы в файл» на вкладке «План»: текст диктовки, главное по темам, вопросы для самопроверки и ваши вопросы с ответами (через «Поделиться» — в Telegram, Google Диск и т. п.).

## Голос

- **Голос Android** — системный синтезатор. Чтобы звучал естественнее: Настройки телефона → «Синтез речи» → система «Google» → «Установить голосовые данные» → Русский → выбрать голос.
- **Нейросетевой голос** (Настройки → Голос → «Нейросетевой») — модель Piper работает прямо на телефоне, без интернета и лимитов; один раз скачивается около 90 МБ. Голоса: Ирина, Дмитрий, Денис, Руслан. Если не загрузится — приложение говорит голосом Android.
- **Стиль «ИИ-ассистент в стиле Джарвиса»** (Настройки → Голос → Стиль) — стилизация под ассистента из кино: тон ниже, «цифровой» оттенок, лёгкое эхо и обращение «сэр» (можно «мэм» или без обращения). Это не копия голоса актёра. Полный эффект — с нейросетевым голосом; голосу Android можно только понизить тон.

## Облачный голос «как живой человек»

Настройки → Голос → **«Облачный — как живой»**. Голос звучит как диктор: без запинок и с правильными ударениями. Озвученные куски сохраняются на телефоне, поэтому повторное прослушивание бесплатно и работает без интернета. Весь конспект можно озвучить заранее на вкладке «План» → «Озвучить весь конспект заранее».

| Сервис | Звучание | Доступ из России | Стоимость |
|---|---|---|---|
| **Яндекс SpeechKit** | лучший русский, правильные ударения | работает | по тарифам SpeechKit, обычный конспект — порядка сотни-другой рублей |
| **Gemini TTS** | очень естественный | нужен VPN | бесплатный лимит небольшой |
| **ElevenLabs** | самый «человеческий» | нужен VPN | бесплатно около 10 минут в месяц |

### Как подключить Яндекс SpeechKit

SpeechKit не принимает запросы прямо из браузера, поэтому нужна маленькая функция-посредник в Yandex Cloud (её код — `yandex-function/index.js`, в приложении есть кнопка «Скопировать код функции»).

1. Откройте [console.yandex.cloud](https://console.yandex.cloud), войдите через Яндекс ID и создайте платёжный аккаунт.
2. **Сервисные аккаунты** → «Создать» → имя `tts` → роль `ai.speechkit-tts.user`.
3. **Cloud Functions** → «Создать функцию» → имя `tts` → среда Node.js 18 или новее.
4. В редакторе создайте файл `index.js` и вставьте код функции; точка входа `index.handler`; сервисный аккаунт `tts`; таймаут 10 с → «Сохранить изменения».
5. На вкладке «Обзор» включите **«Публичная функция»** и скопируйте ссылку `https://functions.yandexcloud.net/…`.
6. В приложении: Настройки → Голос → «Облачный» → сервис «Яндекс SpeechKit» → вставьте ссылку → 🔊.

## Первый запуск

При первом открытии приложение само проводит через настройку:
1. **Ключ OpenRouter** — кнопка открывает openrouter.ai/keys; создаёте ключ, вставляете его кнопкой «Вставить». Приложение проверит ключ, само подберёт лучшую бесплатную модель (с распознаванием фото) и две запасные — если основная перегружена, запросы уйдут на запасную. Проверка полноты кусков выключается, чтобы хватало дневного лимита бесплатных запросов.
2. **Звук и микрофон** — прослушать голос и разрешить микрофон.

Повторить настройку можно в **Настройки → Настроить заново**; другого провайдера — в «Настроить вручную».

## Какую нейросеть выбрать и где взять ключ

Провайдер, ключ и модель задаются в **⚙ → Нейросеть**. Кнопка «Проверить ключ» загружает список доступных моделей. Ключи хранятся только в вашем браузере и отправляются напрямую провайдеру.

| Провайдер | Ключ | Из России | Фото страниц |
|---|---|---|---|
| **OpenRouter** (по умолчанию) | [openrouter.ai/keys](https://openrouter.ai/keys) | работает | да (модели с поддержкой картинок) |
| **Claude (Anthropic API)** | [console.anthropic.com](https://console.anthropic.com/settings/keys) | API заблокирован по стране | да |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey), бесплатно | заблокирован (нужен VPN или прокси) | да |
| **DeepSeek** | [platform.deepseek.com](https://platform.deepseek.com/api_keys) | работает | нет |
| **Mistral** | [console.mistral.ai](https://console.mistral.ai/api-keys) | — | да |
| **Свой адрес** | — | — | зависит от модели |

**OpenRouter** — один ключ на модели Google, Anthropic (Claude), DeepSeek и других; запросы к ним идут с серверов OpenRouter, поэтому региональные блокировки Google и Anthropic не мешают. Бесплатные модели оканчиваются на `:free` (после «Проверить ключ» они в начале списка), но у них небольшой дневной лимит запросов — для анализа большого конспекта отключите «Проверку полноты» или пополните баланс. Модель по умолчанию — `google/gemini-2.5-flash`; Claude там называется `anthropic/claude-…`.

**Claude напрямую** — модель по умолчанию `claude-opus-5-5`, для экономии можно выбрать `claude-sonnet-5-5` или `claude-haiku-5-5`. Нужен ключ API с оплатой в console.anthropic.com: подписка claude.ai (Pro/Max) доступа к API не даёт. Запросы из браузера идут с заголовком `anthropic-dangerous-direct-browser-access`, ключ видит только ваш браузер.

**Gemini** — бесплатный ключ в Google AI Studio, но из неподдерживаемых стран Google отвечает «User location is not supported»; приложение покажет понятное сообщение.

При превышении лимитов приложение само подождёт и повторит запрос.

## Как запустить на телефоне

Микрофону и установке PWA нужен **HTTPS**, поэтому файл нельзя просто открыть с диска телефона — разместите папку на бесплатном хостинге.

**GitHub Pages**
1. Загрузите файлы репозитория в GitHub-репозиторий.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите ветку и папку `/ (root)`, **Save**.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

**Netlify**
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку с файлами (`index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/`).
3. Netlify выдаст адрес `https://….netlify.app`.

Откройте адрес в **Chrome на Android**, разрешите доступ к микрофону при первой диктовке. Для компьютера можно запустить локально: `npx http-server .` и открыть `http://localhost:8080` (localhost считается безопасным).

## Как установить на главный экран

Откройте адрес в Chrome на Android и нажмите **«Установить»** на карточке «Установить как приложение» (или меню ⋮ → «Установить приложение»). Chrome установит его как обычное Android-приложение: своя иконка в списке приложений, отдельное окно без адресной строки, удаление как у любого приложения. Долгое нажатие на иконку — быстрое действие «Продолжить диктовку». Настройки и прогресс, сделанные в браузере, сохраняются и в установленном приложении.

## Советы

- Используйте **наушники**: так микрофон не слышит синтезатор, и голосовые команды срабатывают надёжнее. Без наушников основной способ прерывания — кнопка.
- Голос прерывается или звучит глухо, «как по телефону»? Настройки → Диктовка → Микрофон → **После «СТОП»**, и включите «Кнопки наушников», чтобы останавливать и продолжать кнопкой на наушниках.
- Если русский голос звучит плохо, установите голосовые данные: Android → Настройки → Синтез речи → Google → русский язык.
- Опция «Прерывать при любой моей речи» останавливает диктовку на любую фразу — включайте её только в наушниках.

## Структура

```
index.html            разметка и экраны
css/styles.css        тёмная mobile-first тема
js/app.js             интерфейс, план, фоновая подготовка кусков
js/dictation.js       движок диктовки: прерывание, вопросы, возврат к куску
js/speech.js          SpeechSynthesis, SpeechRecognition, команды, защита от эха, Wake Lock
js/analyze.js         темы, план, оценка времени, генерация кусков и проверка полноты
js/ai.js              выбор провайдера нейросети
js/gemini.js          клиент Gemini API
js/anthropic.js       клиент Anthropic Messages API (Claude)
js/openai.js          клиент OpenAI-совместимых API (OpenRouter, DeepSeek, Mistral, свой адрес)
js/extract.js         txt/md/pdf/docx/фото
js/storage.js         localStorage (настройки, позиция) и IndexedDB (проект)
sw.js, manifest.webmanifest, icons/
```

**Выпуск новой версии.** Поднимите одно и то же число в `VERSION` в `sw.js` и в `?v=` в `index.html` (importmap и `js/app.js`). Тогда все файлы новой версии загружаются вместе и не смешиваются со старыми из кэша браузера. Если запуск всё же сорвался, страница один раз сама перезагрузится со свежими файлами, а затем покажет, что данные на месте.
