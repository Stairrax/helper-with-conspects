# Диктор конспектов

Мобильное веб-приложение (PWA), которое диктует конспекты голосом короткими кусками, мгновенно останавливается по команде «стоп» или по вопросу, отвечает на вопрос через нейросеть и продолжает с того же места.

Без сборки и без бэкенда: обычные статические файлы. Целевая платформа — Chrome на Android.

## Возможности

- **Материал**: несколько конспектов; вставка текста, файлы `.txt`, `.md`, `.pdf` (pdf.js), `.docx` (mammoth.js), фото страниц (распознаёт Gemini). PDF-сканы без текстового слоя автоматически отправляются в Gemini как изображения.
- **Время и приоритет**: «сколько у меня времени» и порядок: «сначала сложное», «сначала простое», «как в конспектах».
- **Нейросеть на выбор**: OpenRouter (по умолчанию, работает из России, есть бесплатные модели), Claude (Anthropic API), Google Gemini, DeepSeek, Mistral или любой OpenAI-совместимый адрес. Для каждого провайдера можно указать свой адрес API (например, прокси).
- **Анализ** (один раз): разбиение на темы без потери текста (модель только расставляет границы между блоками исходника, сам текст не переписывается), сложность 1–5, зависимости, план с учётом зависимостей, оценка времени по объёму и сложности. План можно править: переставлять, пропускать темы, начинать с любой темы, подогнать паузу под бюджет времени.
- **Куски для диктовки**: 1–3 предложения, весь исходный материал, переформулированный для устной речи, формулы словами, пояснения и примеры в сложных местах. **Проверка полноты**: список всех пунктов исходника с номерами кусков, где они покрыты; непокрытые пункты догенерируются. Куски готовятся в фоне с опережением — диктовку можно начинать сразу после анализа.
- **Диктовка**: SpeechSynthesis `ru-RU`, пауза между кусками (по умолчанию 3 с, дольше для сложных тем и длинных кусков), прогресс по темам и времени, текст куска можно скрыть. Позиция сохраняется — можно закрыть и продолжить.
- **Прерывание**: большая кнопка «СТОП / ВОПРОС» срабатывает на касание (`pointerdown`) и сразу вызывает `speechSynthesis.cancel()`. Голосовые команды распознаются непрерывно параллельно с диктовкой (с авто-перезапуском): «стоп», «пауза», «дальше», «повтори», «повтори тему», «медленнее», «быстрее», «пропусти тему», «продолжай». Вопрос можно начать сразу словами «почему…», «что такое…», «вопрос…» — диктовка остановится на первом же промежуточном результате распознавания.
- **Защита от эха**: пока звучит синтезатор, фразы, совпадающие по словам и порядку с только что произнесённым, игнорируются.
- **Вопросы**: голосом или текстом; нейросеть отвечает с учётом всего конспекта и уже продиктованного, ответ озвучивается по мере генерации (потоково). Затем «Продолжаем?» — по «да» / «дальше» диктовка возвращается к началу прерванного куска. После каждой темы — «Есть вопросы?».
- **Режимы**: «всё подряд» (после темы короткая пауза на вопросы) или «по теме с вопросами после каждой» (ждёт ответа).
- Wake Lock во время диктовки, офлайн-оболочка (service worker), повтор запросов при ошибках сети и лимитах API, большие конспекты обрабатываются по частям.

## Первый запуск

При первом открытии приложение само проводит через настройку:
1. **Ключ OpenRouter** — кнопка открывает openrouter.ai/keys; создаёте ключ, вставляете его кнопкой «Вставить». Приложение проверит ключ, само подберёт лучшую бесплатную модель (с распознаванием фото) и две запасные — если основная перегружена, запросы уйдут на запасную. Проверка полноты кусков выключается, чтобы хватало дневного лимита бесплатных запросов.
2. **Звук и микрофон** — прослушать голос и разрешить микрофон.

Повторить настройку можно в **Настройки → Настроить заново**; другого провайдера — в «Настроить вручную».

## Какую нейросеть выбрать и где взять ключ

Провайдер, ключ и модель задаются в **⚙ → Нейросеть**. Кнопка «Проверить ключ» загружает список доступных моделей. Ключи хранятся только в вашем браузере и отправляются напрямую провайдеру.

| Провайдер | Ключ | Из России | Фото страниц |
|---|---|---|---|
| **OpenRouter** (по умолчанию) | [openrouter.ai/keys](https://openrouter.ai/keys) | работает | да (модели с поддержкой картинок) |
| **Claude (Anthropic API)** | [console.anthropic.com](https://console.anthropic.com/settings/keys) | API заблокирован по стране | да |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey), бесплатно | заблокирован (нужен VPN или прокси) | да |
| **DeepSeek** | [platform.deepseek.com](https://platform.deepseek.com/api_keys) | работает | нет |
| **Mistral** | [console.mistral.ai](https://console.mistral.ai/api-keys) | — | да |
| **Свой адрес** | — | — | зависит от модели |

**OpenRouter** — один ключ на модели Google, Anthropic (Claude), DeepSeek и других; запросы к ним идут с серверов OpenRouter, поэтому региональные блокировки Google и Anthropic не мешают. Бесплатные модели оканчиваются на `:free` (после «Проверить ключ» они в начале списка), но у них небольшой дневной лимит запросов — для анализа большого конспекта отключите «Проверку полноты» или пополните баланс. Модель по умолчанию — `google/gemini-2.5-flash`; Claude там называется `anthropic/claude-…`.

**Claude напрямую** — модель по умолчанию `claude-opus-5-5`, для экономии можно выбрать `claude-sonnet-5-5` или `claude-haiku-5-5`. Нужен ключ API с оплатой в console.anthropic.com: подписка claude.ai (Pro/Max) доступа к API не даёт. Запросы из браузера идут с заголовком `anthropic-dangerous-direct-browser-access`, ключ видит только ваш браузер.

**Gemini** — бесплатный ключ в Google AI Studio, но из неподдерживаемых стран Google отвечает «User location is not supported»; приложение покажет понятное сообщение.

При превышении лимитов приложение само подождёт и повторит запрос.

## Как запустить на телефоне

Микрофону и установке PWA нужен **HTTPS**, поэтому файл нельзя просто открыть с диска телефона — разместите папку на бесплатном хостинге.

**GitHub Pages**
1. Загрузите файлы репозитория в GitHub-репозиторий.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите ветку и папку `/ (root)`, **Save**.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

**Netlify**
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку с файлами (`index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/`).
3. Netlify выдаст адрес `https://….netlify.app`.

Откройте адрес в **Chrome на Android**, разрешите доступ к микрофону при первой диктовке. Для компьютера можно запустить локально: `npx http-server .` и открыть `http://localhost:8080` (localhost считается безопасным).

## Как установить на главный экран

Откройте адрес в Chrome на Android: меню ⋮ → **Установить приложение** (или «Добавить на главный экран»). Приложение откроется в отдельном окне без адресной строки.

## Советы

- Используйте **наушники**: так микрофон не слышит синтезатор, и голосовые команды срабатывают надёжнее. Без наушников основной способ прерывания — кнопка.
- Если русский голос звучит плохо, установите голосовые данные: Android → Настройки → Синтез речи → Google → русский язык.
- Опция «Прерывать при любой моей речи» останавливает диктовку на любую фразу — включайте её только в наушниках.

## Структура

```
index.html            разметка и экраны
css/styles.css        тёмная mobile-first тема
js/app.js             интерфейс, план, фоновая подготовка кусков
js/dictation.js       движок диктовки: прерывание, вопросы, возврат к куску
js/speech.js          SpeechSynthesis, SpeechRecognition, команды, защита от эха, Wake Lock
js/analyze.js         темы, план, оценка времени, генерация кусков и проверка полноты
js/ai.js              выбор провайдера нейросети
js/gemini.js          клиент Gemini API
js/anthropic.js       клиент Anthropic Messages API (Claude)
js/openai.js          клиент OpenAI-совместимых API (OpenRouter, DeepSeek, Mistral, свой адрес)
js/extract.js         txt/md/pdf/docx/фото
js/storage.js         localStorage (настройки, позиция) и IndexedDB (проект)
sw.js, manifest.webmanifest, icons/
```
