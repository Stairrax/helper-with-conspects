        Голос

        Как сделать голос iPhone естественнее
        1. Настройки → Универсальный доступ → Устный контент → Голоса → Русский.
        2. Выберите голос с пометкой «улучшенный» (например, «Милена») и скачайте его.
        3. Вернитесь сюда и нажмите 🔊, чтобы послушать.
        Как сделать голос Android естественнее
        1. Настройки телефона → поиск «Синтез речи» (или «Преобразование текста в речь»).
        2. Предпочтительная система — «Синтезатор речи Google» / «Речевые сервисы Google».
        3. Шестерёнка рядом → Установить голосовые данные → Русский → выберите голос (их несколько) и скачайте.
        4. Вернитесь сюда и нажмите 🔊, чтобы послушать.

        Работает прямо на телефоне, без интернета и лимитов. Живые голоса (Бая, Ксения, Ксюша, Айдар, Евгений) один раз скачиваются вместе — около 120 МБ, остальные — около 65 МБ каждый; лучше по Wi-Fi. Если голос не загрузится, приложение будет говорить голосом Android.

        На iPhone живым голосам может не хватить памяти браузера — если страница перезагружается во время загрузки голоса, выберите голос iPhone.

        Живые голоса — модель Silero (© Silero Team, лицензия CC BY-NC-SA 4.0: только некоммерческое использование). Остальные — Piper.

        Голосовые команды
        • стоп — остановить и задать вопрос; пауза — просто пауза
        • продолжай — с прерванного куска
        • дальше, повтори, повтори тему, пропусти тему
        • медленнее, быстрее
        • как пишется … / по буквам — продиктовать слово по буквам
        • записал / готово — в паузе: дальше; пока читается новый кусок — ничего не пропускается
        • сразу вопросом: почему…, что такое…, вопрос…
        • после ответа: да / дальше
        • перейди к третьей теме, к теме налоги, предыдущая тема, последняя тема, какая сейчас тема
        • покажи формулы, формулы следующей темы, закрой формулы
        • открой план / настройки, только слушаю, режим записи, паузы подольше / покороче
        • включи / выключи сокращения, интонацию, самопроверку; светлая / тёмная / неоновая тема; скрой текст; сохрани конспект
        • что ты умеешь — список команд. Можно и своими словами («сделай паузы покороче») — нейросеть поймёт, что сделать. Команды работают и текстом в поле вопроса
        • stop — остановить и задать вопрос; pause — просто пауза
        • continue — с прерванного куска
        • next, repeat, repeat topic, skip topic
        • slower, faster
        • spell … / how do you spell … — продиктовать слово по буквам
        • done / got it — в паузе: дальше; пока читается новый кусок — ничего не пропускается
        • сразу вопросом: why…, what is…, question…
        • после ответа: yes / next
        • go to topic three, go to the topic taxes, previous topic, last topic, what topic is this
        • show formulas, formulas for the next topic, close formulas
        • open the plan / open settings, listen only, writing mode, longer pauses / shorter pauses
        • light theme / dark theme / neon theme; hide text; save the notes
        • what can you do — список команд. Можно и своими словами («make the pauses shorter») — нейросеть поймёт, что сделать. Команды работают и текстом в поле вопроса

        Данные

        Звук и микрофон

        Проверьте, что слышно голос, и разрешите микрофон — он нужен для команд «стоп», «дальше» и вопросов голосом. Голос Android звучит механически. Живой голос «Бая» работает прямо на телефоне, без интернета: его один раз скачивают — около 120 МБ, лучше по Wi-Fi.
