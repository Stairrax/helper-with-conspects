# Неизменяемые релизы PWA

Исходный код остаётся в js/, css/, index.html и sw.js. Сборка не требует новых npm-зависимостей.

```sh
npm run build
npm run preview
```

Откройте http://127.0.0.1:8081/helper-with-conspects/. Порт можно изменить переменной PORT. Локальный исходный режим npm start остаётся доступен.

Каждая сборка получает путь releases/vНОМЕР-ХЕШ/. Номер берётся из sw.js; несовпадение с index.html останавливает сборку. Хеш зависит от исходников и сценария сборки. Повторная сборка проверяет уже существующие файлы и не перезаписывает неизменяемые релизы. Не удаляйте dist/releases между сборками, если тестируете обновления. Для чистого CI используйте --history с каталогом предыдущих releases. Сборщик проверяет контрольные суммы архивных файлов.

Корневые URL приложения, manifest.webmanifest и область Service Worker остаются прежними. HTML ссылается на неизменяемые JS/CSS; шрифты находятся внутри релиза, голосовые модели — в общем voices/. Service Worker проверяет SHA-256 всех файлов перед установкой, отдаёт согласованную оболочку из кэша и не принуждает старые вкладки к обновлению. Старые страницы могут догружать собственные модули по неизменяемым URL. После закрытия старых вкладок новый worker активируется обычным способом. Кэши других приложений и ранее скачанные голоса не удаляются.

Пока это тестовый механизм. Не переключайте Pages на GitHub Actions, пока не пройдёт проверка сборки, перехода между двумя релизами и офлайн-запуска. Первая миграция с прежнего network-first SW требует отдельного теста на реально опубликованной версии; старый worker не может обеспечить новые гарантии задним числом.

При публикации обязательно сохранять архив предыдущих релизов между деплоями. GitHub Pages заменяет содержимое артефакта целиком. Не удалять архив автоматически без отдельной политики хранения. Следить за размером Pages. Для первого перехода можно передать --legacy /путь/к/снимку/опубликованного/исходного/релиза, чтобы сохранить прежние корневые js/css/fonts для открытых страниц. Это временная совместимость, а не гарантия для всех дорелизных версий.
